# Accessibility Baseline & Repository Architecture Audit

## Project Overview

This repository contains the accessibility baseline and maintainable repository architecture created as part of the RabTech Academy Full Stack Web Development Internship.

The project uses a real public-service website as a reference for identifying accessibility, semantic structure, responsive design, and maintainability requirements.

## Reference Website

**National Portal of India**

https://www.india.gov.in/

## Audit Focus

The audit focuses on:

* Semantic HTML5 structure
* WCAG 2.1 accessibility principles
* Keyboard navigation
* Accessible forms
* Image alternative text
* Heading hierarchy
* Color and contrast
* Responsive design
* Maintainable project architecture

## Accessibility Principles

The project follows the four core WCAG principles:

1. **Perceivable**
2. **Operable**
3. **Understandable**
4. **Robust**

## Maintainability Goals

The architecture is designed to support:

* Reusable components
* Separation of concerns
* Responsive layouts
* Accessible interfaces
* Clear documentation
* Future API and backend integration
